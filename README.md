# Личные быстрые заметки для Битрикс24

Локальный модуль для коробочной версии Битрикс24. Добавляет авторизованным сотрудникам плавающую кнопку **«Мои заметки»** и выдвижной виджет, не требующий перехода на отдельную страницу.

## Возможности

- создание нескольких личных заметок;
- удаление заметок;
- дата и время создания;
- персональное хранение средствами `CUserOptions`;
- ограничение до 100 заметок по 2 000 символов;
- CSRF-защита штатным `sessid` Битрикс;
- экранирование пользовательского текста;
- адаптация интерфейса для мобильных экранов;
- отсутствие изменений ядра Битрикс24.

## Требования

- коробочная версия Битрикс24;
- PHP 8.0 или новее;
- доступ администратора к файловой системе портала и административному разделу.

## Установка

1. Скопируйте каталог модуля в:

   ```text
   /local/modules/local.quicknotes/
   ```

2. Откройте административный раздел Битрикс24.
3. Перейдите в **Marketplace → Установленные решения**.
4. Найдите модуль **«Личные быстрые заметки»** и нажмите **«Установить»**.
5. Обновите страницу портала. В правом нижнем углу появится кнопка **«Мои заметки»**.

## Удаление

Удалите модуль штатно в разделе **Marketplace → Установленные решения**. Сохранённые пользовательские заметки намеренно остаются в базе, чтобы их можно было восстановить после повторной установки.

## Структура

```text
local.quicknotes/
├── assets/             # JavaScript и CSS виджета
├── install/            # установщик и версия модуля
├── lang/ru/install/    # русская локализация установщика
├── public/             # AJAX-обработчик и совместимость со старым URL
└── include.php         # подключение ресурсов на страницах портала
```

## Безопасность

AJAX-обработчик доступен только авторизованным пользователям. Идентификатор владельца определяется серверной сессией, а не передаётся браузером. Все изменяющие запросы проверяются через `check_bitrix_sessid()`.
